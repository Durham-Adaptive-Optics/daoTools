.. _citing:

How to Cite
===========

If you use DAO or daoTools in academic work, please cite **daoBase**, the core
DAO library on which daoTools depends. This gives credit to the contributors
and links your work to the specific software release used.

The canonical daoBase DOI is:

**DOI:** `10.5281/zenodo.17264152 <https://doi.org/10.5281/zenodo.17264152>`_

BibTeX Citation
---------------

.. code-block:: bibtex

   @software{barr_2025_17264152,
   author       = {Barr, David and
                   Cetre, Sylvain and
                   Connolly, John and
                   Thomas Davies},
   title        = {Durham-Adaptive-Optics/daoBase: Initial Release},
   month        = oct,
   year         = 2025,
   publisher    = {Zenodo},
   version      = {v0.0.1},
   doi          = {10.5281/zenodo.17264152},
   url          = {https://doi.org/10.5281/zenodo.17264152},
   }

Standard Citation Format
------------------------

For non-BibTeX formats, adapt the following citation to the style required by
your publisher:

   Barr, D., Cetre, S., Connolly, J., & Thomas Davies. (2025).
   Durham-Adaptive-Optics/daoBase: Initial Release (v0.0.1). Zenodo.
   https://doi.org/10.5281/zenodo.17264152

See the `daoBase citation page
<https://daobase.readthedocs.io/en/latest/cite.html>`_ for the canonical
citation and release-specific guidance.
